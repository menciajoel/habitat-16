# Habitat 16

Experiencia digital para presentar soluciones de automatización residencial de forma clara, accesible y orientada a las necesidades del usuario.

## El producto

Habitat 16 presenta servicios de automatización residencial organizando beneficios, soluciones y proceso de contacto dentro de una experiencia web responsive.

## Mi trabajo

Product Design · UX/UI · Comunicación · Frontend

El trabajo incluye estructuración de la oferta, jerarquía de información, experiencia de navegación y ejecución de la interfaz pública.
